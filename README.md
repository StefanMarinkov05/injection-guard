# agent-guard / injection-guard

Prompt-injection defence for Claude Code agents: a Claude Code plugin marketplace with one plugin, **injection-guard**.

- `plugins/injection-guard/` - the plugin (scanner library, `safe-read` / `safe-fetch`, hooks, skill, quarantine-reader agent, tests). See its [README](plugins/injection-guard/README.md).
- `docs/` - [MECHANISMS.md](docs/MECHANISMS.md) and `docs/build/mechanisms.pdf`: every mechanism with target, attack vector, behaviour and the tests that prove it; red-team log; calibration on real files. Generated by `docs/gen_docs.py` from a recorded test run.

## Install (local marketplace)
```sh
claude plugin marketplace add /path/to/injection-guard
claude plugin install injection-guard@agent-guard --scope user
ln -s "$PWD/plugins/injection-guard/bin/safe-read" ~/.local/bin/safe-read
ln -s "$PWD/plugins/injection-guard/bin/safe-fetch" ~/.local/bin/safe-fetch
```
Dependencies: Python 3 with Pillow, poppler-utils. Optional (more checks): tesseract (eng, deu), mupdf-tools, qpdf, `pypdf`, `fonttools`.

## Tests
```sh
python3 -I plugins/injection-guard/tests/run_tests.py        # whole suite
python3 -I plugins/injection-guard/tests/report.py           # + docs/test_results.json
python3 -I docs/gen_docs.py                                  # regenerate the docs
```
CI runs the suite on every push (`.github/workflows/tests.yml`) in 4 parallel shards balanced by `tests/durations.json` (`report.py --shard K --of 4`); a merge job combines them and fails if a shard failed, a test ran twice or a shard is missing, then `gen_docs.py --check` fails if a test is not mapped to a documented mechanism or a mapped test no longer exists. Refresh the durations after adding slow tests: `report.py --write-durations`. Tests that need local course files skip themselves elsewhere. Never delete a test: each one is an attack that was caught once.
